Implementation
--------------

SAP entries are ordered by minimum X. For every inner-loop pair:

- The ordering guarantees first.min.x <= second.min.x <= second.max.x.
- Continuing past the break guarantees second.min.x <= first.max.x.

Both inclusive X-overlap conditions are therefore already proven. The
specialized loop tests only Y and Z instead of calling the generic six-check
AABB overlap function.

Decision
--------

Retain. Sweep time clears the 10% gate at both target sizes. The reported
5,000-body full-step gain is 1.9%, within the benchmark's 0.01 ms output
rounding of the 2% gate; all three current runs were faster than all three
controls. The 10,000-body gain is 3.0%. The implementation deletes redundant
comparisons, adds no state or allocation, and preserves exact behavior.
