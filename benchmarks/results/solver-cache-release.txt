Temporary storage on arm64:
PreparedBody: 48 bytes per world body slot, allocated only when a manifold is prepared
PreparedContactPoint: 68 -> 140 bytes
PreparedManifold (four-point capacity): 296 -> 584 bytes
One extra allocation per active solve; no persistent RigidBody cache.

Decision: retain both cache layers. Contact response factoring trades extra temporary
storage and changed floating-point rounding for the larger additional solver gain.
