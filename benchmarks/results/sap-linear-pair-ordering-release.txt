Implementation
--------------

SAP emits canonical pairs whose two indices are bounded by the active collider
count. Instead of comparison-sorting those pairs, the retained path performs
two stable counting passes: first by the second index and then by the first.
The result is the same lexicographic order required by the solver.

The temporary pair buffer and count array are retained in the world's existing
broadphase workspace. Sparse outputs continue to use `std::sort`, avoiding
count-array work and scratch storage when the key range exceeds the pair count.
The uniform-grid and dynamic-tree ordering paths are unchanged.

Decision
--------

Retain. Pair ordering improves by about 90%, comfortably exceeding the 50%
subphase gate. The conservative focused runs improve full-step time by 3.6%
and 4.5%, exceeding the 2% gate at both target sizes. Output order and all
reported behavior metrics remain exact.
